# Homebrew Tap for dimelords

Official Homebrew tap for dimelords projects.

## Installation

```bash
brew tap dimelords/tap
brew install protoc-gen-utcp
```

## Available Formulae

- **protoc-gen-utcp** - Protocol Buffer compiler plugin that generates UTCP definitions
